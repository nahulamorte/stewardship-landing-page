# Stewardship Advisor — Landing Page

Stewardship Advisor es una landing page estática diseñada para presentar servicios de asesoría financiera personalizada. El sitio está pensado para comunicar profesionalismo y confianza, mostrar estándares de gestión y facilitar la captación de leads mediante una sección de contacto con formulario y una tarjeta de diagnóstico gratuito.


Objetivo: generar confianza en potenciales clientes y facilitar el primer contacto con la firma de asesoría.

Características principales:
--------------------------
- Diseño responsivo basado en CSS puro.
- Sección de estándares profesionales con tarjetas informativas.
- Sección de contacto con dos tarjetas adyacentes: tarjeta de diagnóstico y formulario de contacto.
- Tipografía y sistema de colores centralizados en variables CSS (:root).


Para visitar el sitio: https://nahulamorte.github.io/stewardship-landing-page/
